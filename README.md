# 质量慧析 · 考试质量分析系统

本地优先的考试质量分析系统。导入质量复盘 Excel 后，可以从年级、考试、类别、班级、学科和学生多个层次进行分析，并导出可交付的 Word、PDF 和 Excel 报告。

> 在线 Pages：[打开质量慧析](https://yusheng266186-beep.github.io/zhiliang-huixi-new-/)  
> GitHub：[查看源代码](https://github.com/yusheng266186-beep/zhiliang-huixi-new-)

## 项目定位

质量慧析把原始考试工作簿转换为可解释的教学分析结果，适合用于：

- 年级考试质量复盘；
- 班级横向对比；
- 学科有效人数和达线情况分析；
- 临界生与薄弱学科诊断；
- 学生画像和历次考试对照；
- 小题得分率与知识点优先级分析；
- 导出会议、教研和班级沟通所需的分析材料。

Pages 版本在浏览器本地解析 Excel、生成图表和导出文件，不依赖服务器端数据库。上传的工作簿默认留在当前浏览器环境中。

## 主要功能

### 考试质量总览

- 年级总成绩；
- 一本、本科上线人数和上线率；
- 学科有效人数与有效率；
- 分数分布光谱；
- 重点指标和证据驱动洞察。

### 班级与类别分析

- 物理类、历史类分别查看；
- 班级横向对比；
- 同类班级基准；
- 班级均分、达线率和学科表现；
- 班级薄弱学科及优先行动方向。

### 学生分析

- 学生画像；
- 历次考试变化；
- 总分和学科趋势；
- 临界生名单；
- 薄弱学科诊断；
- 学生分层行动栈；
- 根据证据生成教学关注点。

### 小题和知识点

- 小题得分率；
- 知识点表现；
- 学科能力矩阵；
- 知识点优先级；
- 题目、知识点和学生表现的关联分析。

### 报告导出

- 详细 Word 报告；
- 分页 PDF 报告；
- 多工作表 Excel 分析包；
- 可将报告用于年级复盘、班级沟通和教研留档。

### 数据健康与容错

- 语义表头识别；
- 导入前确认学校、考试、班级、学生数和字段映射；
- 学号存在时优先作为稳定身份，无学号时明确提示降级口径；
- 重复记录显示原始行号，并允许保留首行、末行或全部记录；
- 重构总分由用户明确确认后才纳入；
- 缺失字段降级；
- 缺失总分时按规则重建；
- 损坏文件和不完整工作簿保护；
- 对数据置信度进行提示。

## 当前数据口径

项目内置了本届固定口径，使用真实工作簿验收基准进行解析和分析测试：

- 7班源表中的“英语”按“日语”展示和分析；
- 9班源表中的“生物”及小题按“地理”展示和分析；
- 物理类和历史类混合查看时，每名学生按自己的类别分数线判断上线；
- 不使用物理类、历史类平均分数线替代个人类别分数线；
- 缺失总分时，至少有4门有效学科才重建，并标记为“重建”；
- 缺失学科不会按0分参与均值；
- 学生基础表改名、插入空列、字段改名或缺失小题表时，系统按语义表头继续工作，并降低对应模块置信度。

## 启动开发环境

要求：

- Node.js >= 22.13.0；
- npm；
- 支持现代 JavaScript、TypeScript 和浏览器 API 的开发环境。

安装依赖：

    npm install

启动开发服务器：

    npm run dev

默认打开终端显示的本地地址，通常是：

    http://localhost:5173

如果环境不需要 Cloudflare 相关接口，可以尝试：

    SKIP_CLOUDFLARE=1 npm run dev -- --host 127.0.0.1

## 常用命令

    npm run build
    npm run lint
npm run test
npm run test:parser -- "/path/to/质量复盘.xlsx"
npm run test:import-review -- "/path/to/质量复盘.xlsx"
npm run test:analytics -- "/path/to/质量复盘.xlsx"

说明：

- build：构建应用；
- lint：检查代码质量；
- test：构建并运行渲染 HTML 测试；
- test:parser：验证工作簿解析、字段映射和容错；
- test:import-review：验证导入确认、重复策略、学号覆盖和重构总分开关；
- test:analytics：验证统计分析和指标结果。

真实工作簿验收基准为：

- 7,255 条成绩；
- 11 次考试；
- 19 条分数线；
- 16,047 条小题答题记录。

解析和分析脚本还会测试插入空列、字段改名、缺失学科、缺失总分和缺失小题表等变体。

## GitHub Pages 发布

仓库内置 .github/workflows/pages.yml。推送到 main 后，工作流会：

1. 安装 npm 依赖；
2. 执行 npm run build:pages；
3. 生成静态 Pages 构建；
4. 发布到 GitHub Pages。

Pages 地址：

    https://yusheng266186-beep.github.io/zhiliang-huixi-new-/

Pages 版本使用浏览器端处理 Excel、图表和 Word/PDF/Excel 导出，不依赖服务器端数据库。发布失败时，先检查 Actions 日志，再检查 pages-static、vite.pages.config.ts 和构建输出。

## 数据隐私与安全

这是教育数据项目，使用真实成绩时必须谨慎：

- 不要把包含真实姓名、学号、手机号或身份证号的工作簿提交到公开仓库；
- 不要把导出的学生报告上传到公开 Pages；
- 公开演示时使用脱敏或虚构数据；
- 本地浏览器 IndexedDB 中的成绩数据可能被同一设备上的浏览器配置访问；
- 共用电脑或公共浏览器使用后，应清除站点数据；
- 分享截图、报告和链接前，检查是否暴露学生身份；
- 若要给学校或年级正式使用，建议部署到有身份认证和访问控制的内部环境。

## 开发建议

- 修改解析规则后同时更新 parser 测试和 README 中的口径；
- 修改指标定义时，记录计算口径和数据来源；
- 修改导出模板后测试 Word、PDF 和 Excel 三种输出；
- 修改 Pages 构建时同时测试本地开发和静态发布；
- 不要用缺失值填充0来掩盖数据质量问题；
- 对异常字段和低置信度结果保持可见提示。
